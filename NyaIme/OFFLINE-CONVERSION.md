# RinIME オフラインかな漢字変換

## 使い方

ランチャー画面で「IME設定を開く」を押し、「RinIME オフライン」を有効にする。その後「入力方法を選ぶ」で「RinIME オフライン」を選択する。画面の選択状態表示が「RinIME オフライン 1.5 が選択されています。」になることを確認する。

キーボード左端の一番上にある「オフ／ライン」（2行表示）または「AI」を短くタップして切り替える。表示は現在の状態を示し、候補欄にも「オフライン」または「AI変換」が表示される。設定は保存され、初期値はオフライン。オフラインではオンラインクライアントを呼ばず、入力を外部へ送信しない。AI変換では既存のストリーミングAPIを使用し、先にローカル候補を表示する。APIが失敗した場合はローカル候補を残す。

旧ビルドのパッケージIDは`com.companyname.NyaIme`、今回のプロジェクトは`com.companyname.Nyalme`で、Android上では別アプリとして共存できる。1.0では両方のIME表示名がRinIMEだったため、新しい設定画面を開いていても旧IMEが選択されている場合がある。1.1では新しいIMEを「RinIME オフライン」と区別し、ランチャー画面で旧版選択を検出して案内する。今回パッケージIDをさらに変更したり、旧版を削除したりしていない。

入力を止めると既存の500 ms待機後に候補を表示する。候補をタップすると確定。元の入力も必ず候補に含める。「予測:」は入力途中の単語を補完する候補。確定までは入力本文を書き換えない。

1.3では未確定の入力範囲を保持しながら、現在のカーソル左側だけを変換対象にする。例：`にほんご｜をべんきょう`（｜はカーソル）では`にほんご`を変換し、候補`日本語`の確定後は`日本語｜をべんきょう`となる。右側の入力を残し、カーソルも置換した部分の直後に置く。先頭では左側が空なので候補を一時停止するが、入力範囲を捨てず、右へ移動すれば再開する。

範囲選択時は順方向・逆方向とも選択した部分だけを変換する。対象外の文字列を両側に残す。途中への挿入・削除はカーソル位置に応じた対象を再生成する。追跡範囲の外では変換を停止し、範囲へ戻ると再開する。対象の位置・選択の世代・入力の世代を候補に紐付け、移動前や編集前、別入力欄の候補を現在位置へ適用しない。Enter・候補選択・入力モード変更・入力欄を閉じる操作を明示的な確定／終了として扱う。外部貼付け等で追跡した文字列と実際の入力が一致しなくなった場合は、安全に変換対象を解除し外部編集を上書きしない。1.2の全文確定動作から変更している。

変換方式を切り替えても入力範囲は保持する。古いリクエストをキャンセルし、入力の版と方式の世代が一致する結果だけを表示する。オフラインではネットワーク処理を呼ばない。AIモードのローカル仮候補は上部に「AI応答待ち・ローカル候補」、AI応答がない場合は「AI応答なし・ローカル候補」と表示する。これによりモードと候補の出所を区別できる。

## 方式・ライセンス

独自のC#変換器で、Mozc公式OSS辞書の全1,284,987エントリー、745,965読みと2672×2672の品詞接続コストを利用する。48経路のビーム探索で複数単語・活用を組み合わせる。Mozc本体のJNI/C++統合は既存.NET Android構成への影響が大きいため、今回は辞書と接続コストのみを利用した。ニューラルモデル、GPU、VRAM、外部サーバーは不要。

公式資料：

- https://github.com/google/mozc
- https://github.com/google/mozc/blob/master/LICENSE
- https://github.com/google/mozc/blob/master/src/data/dictionary_oss/README.txt
- https://github.com/google/mozc/blob/master/src/data_manager/gen_connection_data.py

MozcコードのライセンスはBSD 3-Clause。辞書にはNAIST/IPAdic、ICOT、Public Domainの通知がある。`Assets/MOZC-LICENSE.txt`と`MOZC-DICTIONARY-NOTICES.txt`をソース・APKに同梱し、ランチャー画面から全文を読める。新しい変換器はMozc本体のコードを組み込んでいない。辞書取得時点のコミット、各ファイルのSHA256、生成データのSHA256は`MOZC-DICTIONARY-PROVENANCE.json`に記録している。

## サイズと制限

辞書gzipは16,682,585 bytes（約15.9 MiB）。PC上の.NETテストでは保持ヒープ約75 MiB、初回読込約1.3秒、今回の短文変換0〜11 ms。Android端末でのメモリ・応答速度は未測定。辞書はバックグラウンドで読込み、変換もCPUのバックグラウンド処理で行う。

入力上限256 UTF-16コード単位。超過時は原文だけを返す。予測は2〜32文字のかな単語のみ、辞書の前方一致512読みを調べ最大4候補。全文変換は最大8候補、予測追加時は最大12候補。

Mozc本体の書換え・学習・文脈処理・専用文節境界変更UIはない。全角カタカナは検索できるが、半角カナ・結合濁点の正規化は未対応。未知語・新語・人名、長文の候補順位は限界がある。入力の訂正は削除・再入力で行い、オフラインでAIによる誤字推定や`<m>`補完は行わない。自動分割は単語の格子探索であり、Mozcの文節モデルと同等ではない。

オンラインクライアント内の既存APIキーと既存処理は変更していない。APKを配布する前に、埋込みキーを除去・失効し、サーバー経由等への移行を行うこと。

## ビルドと検証

.NET 10 SDK、Android workload 36.1、Android SDK/JDKがこのPCにあり、Releaseビルド可能。プロジェクトコンテナ`andriod_ime`で実行する：

```powershell
dotnet run --project tests/OfflineChecks -- NyaIme/Assets/offline-dictionary.gz
dotnet build NyaIme/NyaIme.csproj -c Release -m:1
```

テストはAndroid・HTTPクライアントをリンクせず、通常のネットワーク制限環境でも実行できる。191項目：実辞書候補、活用・文、原文・URL・絵文字・改行保持、同音異義語、再入力訂正、予測、キャンセル、置換範囲、カーソルの先頭・途中・末尾・範囲外移動、途中挿入・削除・逆向き選択範囲・ドラフト置換、別エディター移動、変換方式の双方向切替・遅延応答・保存値復元・再表示、オフラインでネットワーク関数を呼ばないこと、既存オンライン経路、オンライン失敗時のフォールバック等。実際のAndroidウィジェットやInputConnectionはテスト実行ファイルに含めず、アプリと共通の範囲・方式・経路ロジックを検証する。Android画面上での候補タップ・文字移動・エディター連携は実機未検証。

辞書を再生成する場合は、provenance記載のコミットから`dictionary00.txt`〜`dictionary09.txt`と`connection_single_column.txt`を取得し、次を実行する（生成後は通知とprovenanceも更新する）：

```powershell
dotnet run --project tools/DictionaryBuilder -- <辞書ソースディレクトリ> NyaIme/Assets/offline-dictionary.gz
```

APK出力：`NyaIme/bin/Release/net10.0-android36.0/com.companyname.Nyalme-Signed.apk`。

導入は本人がAPKを端末へコピーして開き、ランチャーの「IME設定を開く」でRinIMEを有効にし、入力方法として選択する。この作業ではインストールを実行していない。機内モードでかな入力、候補確定、原文選択、削除・再入力、カーソル移動、予測、アプリ切替を確認する。同一アプリIDの既存版と署名が異なる場合は更新が拒否されるため、既存版を無断で削除しない。

## 1.4 部分確定の継続

候補確定は対象部分だけを置換し、残りの読みに setComposingRegion を設定し直す。残りの候補を自動再生成し、続けて確定できる。中間選択の確定では左右の読みを保持し、移動した側をネイティブ未確定範囲にする。入力欄が範囲設定に対応しない場合は内部の読みを保持して失敗を記録する。

Androidと同じ composing 優先置換を行う模擬入力欄で、本番の確定処理を検証。両モード各2回の3段階確定、選択部分確定、左右の読み保持、古い候補拒否を含む191件が通過。実機入力欄との連携は未検証。

## 1.5 Enterでの無変換確定

候補未選択のEnterは表示中の先頭候補を採用せず、入力済みの文字をそのまま確定する。改行は送らない。未入力または確定後の次のEnterは従来のEnterキーを送る。候補ボタンによる明示的な変換と部分確定は従来通り。残ったローマ字は通常のかな入力処理を完了してから確定する。カーソル位置・選択範囲を維持し、候補取得をキャンセルし世代と対象を無効化する。

オンライン／オフライン、候補表示あり、先頭・途中・末尾、選択範囲、部分確定後、遅延ローカル辞書・オンライン候補を含む273件の回帰テスト。Android入力欄は模擬エディタで検証し、実機は未検証。

## 公開ソースの認証設定

公開用コピーから埋込APIキーを除去した。KanaKanjiClient はキー取得関数を注入でき、指定がなければ実行時の OPENAI_API_KEY を読む。未設定ならHTTPを送信せずローカル候補へ戻る。Androidサービスは既定の構築なので、この公開用ビルドでオンライン変換を使用するにはアプリ側の私有設定から取得関数を接続する必要がある。既存のローカル版と端末の1.5は変更していない。

APK、署名鍵、ビルド出力、個人設定、ログ、生成辞書はGit対象外。辞書は既記載のMozcコミットとDictionaryBuilderから再生成する。16.7MBの辞書のGit同梱は公開先の方針を確認してから判断する。
